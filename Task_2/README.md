## Результати
- **Аналітичний (quad)**: 2.666667

## Висновки
- Метод `quad` дає точний результат з дуже малою похибкою.  
- Метод Монте-Карло дає наближення, точність якого зростає зі збільшенням кількості випадкових точок.  
- Обидва методи підтверджують правильність обчислень, але для практичних застосувань Монте Карло зручний, коли складно інтегрувати аналітично або область інтегрування багатовимірна.
